# Практична робота: Робота з функціями та масивами в JavaScript

## Відповіді на контрольні запитання:

1. **Що таке JavaScript та для чого використовується ця мова програмування?**  
   JavaScript — це мова програмування, яка використовується для створення інтерактивних вебсторінок (анімації, обробка кліків і форм), розробки серверної частини (Node.js) та мобільних застосунків.

2. **Які основні відмінності між JavaScript та Java?**  
   - JavaScript має динамічну типізацію, а Java — сувору статичну.  
   - JavaScript виконується в браузері чи Node.js, а Java компілюється в байт-код для JVM.  
   - JavaScript використовує прототипне наслідування, а Java — класичне об'єктно-орієнтоване.

3. **Яку роль відіграє JavaScript у клієнтській частині вебзастосунків?**  
   Забезпечує інтерактивність сторінки: динамічно змінює елементи DOM, реагує на дії користувача (події), перевіряє введені дані у формах і здійснює обмін даними із сервером без перезавантаження сторінки.

4. **Які типи даних підтримує JavaScript?**  
   - **Примітивні:** number, string, boolean, null, undefined, bigint, symbol.  
   - **Складні:** object (масиви, об'єкти, функції).

5. **Чим відрізняються способи оголошення змінних let, const та var?**  
   - `var` — застарілий спосіб із функціональною областю видимості.  
   - `let` — змінна з блоковою областю видимості (`{}`), яку можна переприсвоювати.  
   - `const` — константа з блоковою областю видимості, значення якої не можна змінювати після оголошення.
